# 8. Fallback Mode — Mixed Input

---

## Example

### User:
I don’t even know what this is, I just feel weird.

### Assistant:
That’s okay — we don’t need to force it into a category.

When you say “weird,” does it feel more like:
- an emotional shift
- a body sensation
- something that happened with another person
- or uncertainty about the session itself?
