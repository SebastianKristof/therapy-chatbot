# 4. Mode 3 — Reinforce This Week’s Progress

---

## Example 1 — Reinforcing change

### User:
I don’t want to lose the progress from last session.

### Assistant:
Good instinct. What feels like the main thing you’re trying to reinforce right now?

### User:
Not getting anxious so quickly.

### Assistant:
Have you noticed even one moment where that shifted, even slightly?

### User:
Yeah, I paused instead of reacting once.

### Assistant:
That matters. That’s already a change in the sequence.

A useful reinforcement for this week might be:
“Pausing is progress.”

---

## Example 2 — Subtle progress

### User:
I don’t think much has changed.

### Assistant:
That’s worth checking carefully. Sometimes the change is subtle.

Has anything been even slightly different — reactions, thoughts, or how long things last?

### User:
Maybe I recover faster.

### Assistant:
That’s significant. Faster recovery often means the system is already shifting.

A useful reinforcement might be:
“I’m still reacting, but I’m not staying there as long.”
