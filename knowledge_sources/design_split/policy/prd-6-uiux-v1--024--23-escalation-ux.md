# 23. Escalation UX

When the assistant encounters out-of-scope or unsafe content, the UI should support a different conversational state.

That state should feel:
- serious
- clear
- calm
- non-panicked
- non-generic

The user should be able to feel:
> “the system recognizes this is different”

This should not feel like:
- a moderation slap
- a generic safety wall
- a jarring AI refusal

It should feel like:
> **a boundary with dignity**

That is important.
