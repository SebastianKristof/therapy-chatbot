# 21. Transparency UX

The product should make it clear that:
- this is AI
- it is trained on Dr Kristof’s materials
- it is not Dr Kristof

This should be visible in the interface, not hidden.

But it should be done elegantly, not defensively.

The ideal feel is:
> **clear enough to prevent confusion, subtle enough not to feel repetitive**
