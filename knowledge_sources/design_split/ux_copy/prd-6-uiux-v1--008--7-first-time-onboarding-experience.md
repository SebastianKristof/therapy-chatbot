# 7. First-Time Onboarding Experience

The first-time experience should be short and very clear.

It should establish four things:

## 1. Identity
This is an AI support companion trained on Dr Kristof’s materials and approach.

## 2. Usefulness
It can help with:
- reflection
- process questions
- trigger mapping
- reinforcement
- session prep

## 3. Boundaries
It is not:
- Dr Kristof
- crisis support
- emergency support
- a replacement for live sessions

## 4. Consent / acknowledgment
The user should actively confirm understanding.

This should be simple, not heavy.
