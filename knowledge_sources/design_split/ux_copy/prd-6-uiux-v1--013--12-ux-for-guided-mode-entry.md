# 12. UX for Guided Mode Entry

When a user chooses a guided mode, the interface should make the transition feel intentional.

The user should feel:
- “I’m now doing something specific”
- “I don’t have to figure out what to say from scratch”

Each mode should ideally begin with:
- a short explanation of what this mode is for
- a clear first prompt

This reduces uncertainty and improves quality of use.
