# 14. Message Design Principles

Messages should be easy to read and psychologically lightweight.

The UI should support:
- comfortable reading pace
- low cognitive load
- clear separation between assistant and user
- a sense of conversational safety

The visual language should not feel:
- gamified
- social
- chaotic
- “chat app for fun”

This is a professional support product.
