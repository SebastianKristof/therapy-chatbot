# 31. Empty / Idle State UX

When the user is not actively in a conversation, the product should still feel gently useful.

The idle state should support:
- orientation
- easy re-entry
- low-friction usefulness

This is a good place to reinforce:
- the 6 modes
- recent useful summaries
- session prep relevance
- low-pressure return

The product should never feel empty or dead, but also not busy or demanding.
