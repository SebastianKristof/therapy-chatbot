# 1. Purpose of This Document

This document defines what the **AskDrKristof user experience should feel like**.

It is not a visual design system and not a front-end implementation plan.

It exists to ensure the product is built with the right:
- emotional feel
- interaction shape
- trust model
- user guidance
- behavioral clarity

The product should feel:
> **calm, clear, structured, private, and useful**

That matters as much as the AI itself.
