# 3. UX Goals

The interface should help the user:

1. know what the tool is for
2. know what the tool is not for
3. quickly find the kind of help they need
4. avoid blank-page / blank-chat paralysis
5. feel psychologically safe and not overwhelmed
6. leave with something useful in a short interaction
7. trust the product without confusing it for Dr Kristof

Those are the core UX jobs.
