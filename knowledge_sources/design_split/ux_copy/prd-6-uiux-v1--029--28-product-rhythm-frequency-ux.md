# 28. Product Rhythm & Frequency UX

The product should feel appropriate for:
- quick check-ins
- short reflective moments
- occasional use between sessions

It should not visually or behaviorally pressure the user into:
- daily streaks
- compulsive check-ins
- dependency loops
- “come back every day” mechanics

This is not a habit app.

That is a very important UX principle.
