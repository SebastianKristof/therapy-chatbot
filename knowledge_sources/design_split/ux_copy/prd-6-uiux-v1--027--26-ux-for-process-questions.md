# 26. UX for Process Questions

This mode should feel:
- confidence-building
- simple
- reassuring
- myth-clearing

Users in this mode often want:
- a fast answer
- a clear explanation
- relief from uncertainty

The UX should support that by being:
- low-friction
- low-drama
- direct
