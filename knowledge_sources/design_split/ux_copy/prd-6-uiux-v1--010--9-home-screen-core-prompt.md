# 9. Home Screen Core Prompt

The primary prompt should be something like:

## **What would help most right now?**

This is much better than:
- “How can I help?”
- “Ask me anything”
- “What’s on your mind?”

Because it immediately creates:
- orientation
- structure
- usefulness
