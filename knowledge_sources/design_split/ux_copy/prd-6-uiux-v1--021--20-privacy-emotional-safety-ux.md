# 20. Privacy & Emotional Safety UX

Because this is a psychologically sensitive product, the interface should feel private.

That means the product should avoid cues that feel:
- public
- performative
- social
- exposed

The user should feel:
> “this is for me, not for display”

This matters deeply in this category.
