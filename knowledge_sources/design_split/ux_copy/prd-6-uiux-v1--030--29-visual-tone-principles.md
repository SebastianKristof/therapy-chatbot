# 29. Visual Tone Principles

Without prescribing exact UI design, the visual tone should generally support:

- softness without “wellness fluff”
- clarity without sterility
- premium simplicity
- calm spacing
- visual quietness
- low-arousal interaction

Avoid visual directions that feel:
- too medical
- too mystical
- too startup-hype
- too playful
- too gamified

The interface should feel:
> **serious, gentle, and high-trust**
