# 24. UX for “Is This Normal?” Use Cases

This is likely to be one of the most-used product surfaces.

That means it should be especially frictionless.

Users asking:
- “is this normal?”
- “should I worry?”
- “what does this mean?”

are often in a lightly activated state.

The UX should support:
- fast entry
- low typing burden
- calming orientation
- clear and bounded answers

This mode is likely to become a flagship experience.
